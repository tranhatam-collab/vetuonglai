# EDU_AI_TUTOR_UI_REAL_SCREEN_SPEC

## Muc tieu

Day la man hinh quan trong nhat cua toan he.

Noi nguoi dung:
- hoc
- hoi
- lam that
- tien bo that

Khong phai man hinh xem video thu dong.

## Layout tong the

Desktop:

--------------------------------
| Sidebar | Main | AI Panel |
--------------------------------

Mobile:

Content
-> AI chat
-> Actions

## 1) Sidebar

### Thanh phan

- danh sach khoa hoc
- danh sach bai hoc
- tien trinh hoc tap

### Yeu cau UX

- nhin vao la biet minh dang o dau
- biet bai tiep theo la gi
- biet dang tien bo toi milestone nao

## 2) Main Content

### Thanh phan

- video / text / pdf (neu co)
- noi dung bai hoc chinh
- khu vuc bai tap / yeu cau thuc hanh

### Nguyen tac

- noi dung phai dan den hanh dong
- moi bai hoc phai co "lam gi ngay" chu khong chi "hieu gi"

## 3) AI Panel (quan trong nhat)

### 3.1 Chat

- AI giai thich theo ngu canh bai hoc hien tai
- User hoi tu do, nhan phan hoi ro rang, de thuc hanh

### 3.2 Suggested Actions

Nut goi y bat buoc:
- [ Lam bai nay ]
- [ Tao project ]
- [ Hoi them ]

### 3.3 Next Step

Luon hien thi 1 buoc tiep theo ro rang de user khong bi dung.

## 4) Project Mode

Khi user chuyen tu hoc sang lam that:
- Task list
- Progress theo milestone
- Submit ket qua

## 5) UX Rule

KHONG:
- khong giong LMS cu
- khong chi video + quiz

PHAI:
- tuong tac lien tuc
- AI luon hien dien nhu mentor
- co luong hoc -> lam -> nhan xet -> cai tien

## 6) Mobile Rule

Thu tu uu tien:
1. Noi dung chinh
2. AI chat
3. Action buttons

Dam bao thao tac bang mot tay, chu de doc, CTA de bam.

## Runtime Truth Checklist

Moi tinh nang tren man hinh AI Tutor phai xac nhan:
- User co hoi va nhan phan hoi that khong?
- User co bat dau duoc task/project that khong?
- He co luu duoc tien trinh/milestone khong?
- Ket qua co the dua sang lop VC de xac minh khong?

Neu chi la UI demo -> NOT DONE.
