# VETUONGLAI_COMPONENT_LIBRARY_SPEC

## Muc tieu

Tao he thong component dung chung toan he Ve Tuong Lai,
dam bao nhat quan ve trai nghiem, toc do build, va chat luong giao dien.

## Nguyen tac component

Moi component phai:
- nhe
- ro
- de hieu
- khong thua

Va phai phu hop voi Future Calm + Human-centered.

## 1) Button

Types:
- primary
- secondary
- ghost

Trang thai toi thieu:
- default
- hover
- active
- disabled
- loading

## 2) Card

Types:
- content
- course
- story
- action

Card phai co version cho desktop + mobile,
ho tro icon, title, summary, action.

## 3) Input

Types:
- text
- select
- search

Yeu cau:
- state ro rang (focus, error, success)
- helper text ngan gon
- keyboard-friendly

## 4) Navbar

Thanh phan:
- logo
- menu
- CTA

Yeu cau:
- sticky on scroll
- responsive menu tren mobile
- uu tien dieu huong hanh trinh

## 5) Modal

Nguyen tac:
- nhe
- khong block user qua muc

Yeu cau:
- co cach dong ro rang
- trap focus dung chuan
- noi dung ngan, de quyet dinh

## 6) Chat Component

Bat buoc:
- AI bubble
- user bubble

Them:
- timestamp
- typing state
- quick actions

## 7) Progress Bar

Khong dung phan tram la trung tam.

Dung:
- level
- milestone

Hien thi ro:
- da dat moc nao
- moc tiep theo la gi

## 8) Tag System

Muc dich:
- level
- trang thai

Vi du:
- Beginner / Intermediate / Advanced
- Live / Preview / Reviewing / Planned

## 9) Layout Block

Khoi co ban:
- section
- grid
- container

Yeu cau:
- spacing system nhat quan
- max-width ro rang
- toi uu doc tren man hinh nho

## 10) Design Rule Toan Thu Vien

Moi component can:
- doc de hieu trong 1-2 giay
- ho tro cac luong tac vu that (khong chi dep)
- co quy tac su dung, khong dung tuy y

## Runtime Truth Checklist

Truoc khi coi component la done:
- Co duoc dung trong flow that khong?
- Co giai quyet van de UX cu the khong?
- Co tao duoc ket qua co the do/kiem chung khong?
- Co guideline de tai su dung nhat quan khong?

Neu chua -> chua duoc dua vao he thong chinh thuc.
