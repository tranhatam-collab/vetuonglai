# VETUONGLAI_ADMIN_PANEL_RUNTIME_TRUTH

Admin panel chỉ được gọi là xong khi:

- admin tạo được course thật
- admin publish được lesson thật
- user học được lesson đó
- user submit được proof
- admin review được proof
- hệ tính được eligibility
- hệ issue được VC
- journey engine cập nhật stage

Nếu chỉ có UI mà chưa có flow này thì chưa xong.
