# 21_DEV_SEQUENCE_LOCK.md

## Mục đích
File này khóa thứ tự triển khai cho toàn bộ team trong giai đoạn V1.0 để:
- không build sai thứ tự
- không làm economy trước trust
- không mở domain planned trước khi core chạy
- không chồng chéo nguồn lực

## Nguyên tắc gốc
1. Trust trước economy.
2. Identity trước unlock.
3. Learning loop trước marketplace.
4. Submission trước credential scale.
5. Runtime truth trước expansion.
6. Completion before expansion.

## Thứ tự chuẩn toàn hệ

## Phase 0 — Governance Lock
Phải có xong trước khi code tiếp:
- Runtime Truth Matrix
- Language Codex + i18n system
- Public Teaser Contract
- Domain Boundaries
- Entitlement spec

### Gate để qua phase
- không còn ngôn ngữ public/internal lẫn nhau
- không còn status mâu thuẫn
- primary nav không trỏ sang planned domains như live

## Phase 1 — Core Foundation
Build / stabilize:
- Root hub
- Member identity shell
- VC public verify
- API orchestration foundation

### Gate để qua phase
- user có thể hiểu hệ
- user có thể login
- root / VC truth aligned

## Phase 2 — Learning Core
Build / stabilize:
- EDU course player shell
- AI tutor baseline
- submission engine
- review engine
- packet readiness logic

### Gate để qua phase
- learning loop chạy end-to-end
- completion không còn là “xem xong”

## Phase 3 — Proof Loop
Build / stabilize:
- submission → packet
- packet → VC claim
- review → badge state
- member dashboard proof summary

### Gate để qua phase
- ít nhất 1–2 proof types chạy được
- root/member/edu/vc đồng bộ
- user có bằng chứng thật đầu tiên

## Phase 4 — Life System Member Depth
Build / deepen:
- LIFE member layer
- FINANCE member depth
- INVEST member preview depth
- GREEN member depth / evidence handoff

### Gate để qua phase
- pass-based access chạy thật
- domain member depth có value thật

## Phase 5 — Journey & Dashboard
Build:
- member dashboard thật
- next-step engine
- cross-domain summary
- recommendations

### Gate để qua phase
- root/member/edu/vc/life/finance/invest/green đã nối được
- next-step logic có dữ liệu thật

## Phase 6 — Economic Expansion (Controlled)
Chỉ khi phase 1–5 đã đủ mạnh mới làm:
- WORK
- MARKET
- AI tools domain
- COMMUNITY basic

### Gate để qua phase
- trust đủ
- entitlement đủ
- no fake marketplace

## Phase 7 — Referral / Specialist / Partner Expansion
Chỉ làm sau khi:
- pass stable
- packs stable
- proof gates stable
- dashboard stable

Build:
- specialist packs
- affiliate clean program
- partner pathways
- limited wallet logic if needed

## Những thứ cấm build sớm
Không được mở public hoặc build sâu trước khi core xong:
- affiliate runtime
