# KIDS_UI_LEARNING_SYSTEM_SPEC

## 0. Mục tiêu

Thiết kế hệ học cho trẻ:
- đơn giản
- an toàn
- không gây nghiện
- không overload
- giúp trẻ làm được thật

## 1. Nguyên tắc UI

- 1 màn hình = 1 hành động
- không scroll dài
- không nhiều chữ
- luôn có hình
- luôn có hướng dẫn

## 2. Layout tổng

```
Header
↓
Lesson Area
↓
Action Area
↓
Next Step
```

## 3. Màn hình chính

### 3.1 Dashboard

Hiển thị: hôm nay làm gì, đang học gì, đã làm gì, bước tiếp theo.

### 3.2 Lesson UI

```
[Video / Image]
[Giải thích đơn giản]
[Trợ lý học giải thích thêm]
[Việc cần làm]
```

### 3.3 Action UI

- viết
- vẽ
- upload
- chọn

### 3.4 Completion

- Done screen
- hiển thị thành quả

## 4. Trợ lý học cho trẻ

Trợ lý học phải:
- giải thích dễ hiểu
- hỏi lại
- gợi ý

Trợ lý học không được:
- trả lời dài
- làm thay
- phức tạp

## 5. Màu sắc

- nền sáng
- màu dịu
- không neon
- không quá "trẻ con"

## 6. Interaction

- click lớn
- font lớn
- không hover-only

## 7. Safety UI

- không chat mở
- không DM
- không user-user trực tiếp

## 8. Definition of Done

- trẻ tự dùng được
- không cần hướng dẫn
- không bị rối
