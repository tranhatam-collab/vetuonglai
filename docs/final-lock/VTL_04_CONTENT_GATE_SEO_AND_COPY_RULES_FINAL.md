# VTL CONTENT GATE SEO AND COPY RULES FINAL

Version: 3.0 FINAL LOCK
Date: 2026-04-09
Status: locked

## Core Rule

Every subdomain keeps public basic content.

No subdomain should become:

- fully empty until payment
- full-content public with no commercial path
- its own isolated checkout island

## Content Depth Model

### Layer A — Public Basic

Required on every subdomain:

- 1 short problem-led intro
- 1 basic explanation
- 1 demo or mini example
- 1 trust block
- 1 CTA that routes to the homepage purchase hub

### Layer B — Member Basic

Available after annual access:

- onboarding interpretation
- cross-domain map
- foundational guides
- entry checklists
- package chooser

### Layer C — Specialist Depth

Available only after the relevant pack purchase:

- deep frameworks
- professional templates
- advanced playbooks
- real operating systems
- specialist workbook and toolkits

### Layer D — Credential / Program

Available only after:

- deeper work completion
- evidence submission
- review
- proof issuance logic

## Routing Contract for Every Deep CTA

Every deep CTA from a subdomain must point back to the homepage hub with parameters that keep the source context.

Recommended pattern:

- `https://vetuonglai.com/?entry=finance&pack=g2`
- `https://vetuonglai.com/?entry=invest&pack=g5`
- `https://vetuonglai.com/?entry=life&pack=g3`

Required preserved values:

- referring domain
- suggested pack
- content slug
- campaign or affiliate code if present

## SEO and Rendering Rules

- public teaser must render server-side
- locked specialist content must not be shipped in full HTML and then hidden with JavaScript
- use structured data for paywalled content correctly
- each page must have one canonical content owner
- mirrors, summaries, and previews must point back to that owner

## Approved Messaging

Use:

- `client tin nhanh hơn vì có proof và link verify`
- `có cơ sở để bảo vệ giá tốt hơn`
- `khó giả mạo hơn và dễ kiểm tra hơn`
- `rút ngắn vòng sàng lọc`
- `hướng tạo giá trị`

Do not use:

- `client tin ngay`
- `giá cao hơn thị trường`
- `không cần phỏng vấn dài`
- `không thể fake`
- `vĩnh viễn tuyệt đối`
- `ai vào cũng kiếm được tiền`
- `mua xong là có affiliate ngay`

## Homepage Messaging Lock

Homepage owns:

- annual-access pricing story
- package comparison story
- system entry story

Subdomains own:

- domain pain point
- domain teaser
- domain demo
- domain trust framing

Subdomains do not own:

- independent pricing narratives
- independent primary checkout flows
- conflicting product taxonomy
