# 15_RUNTIME_TRUTH_MATRIX_V1.md

## Mục đích
File này là nguồn sự thật công khai cho trạng thái V1.0 của toàn hệ `*.vetuonglai.com`.

Mục tiêu:
- khóa cái gì đang live thật
- cái gì đang ở mức member preview
- cái gì mới là planned
- tránh homepage, subdomain, legal, content và dev nói khác nhau
- tránh overpromise ở front-end và underbuild ở backend

## 4 trạng thái chuẩn
### Live
User public vào được, có giá trị thật, không chỉ là teaser.

### Member Preview
Public đã có preview hoặc pilot value, phần sâu mở sau bằng member entitlement.

### Planned
Chưa có public surface usable hoặc mới ở mức roadmap.

### Bridge
Đóng vai trò kết nối sang một layer khác, không phải trải nghiệm chính.
