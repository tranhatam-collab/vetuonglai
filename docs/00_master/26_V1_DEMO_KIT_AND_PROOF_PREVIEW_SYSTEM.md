# 26_V1_DEMO_KIT_AND_PROOF_PREVIEW_SYSTEM.md

## Mục đích của file

Khóa hệ demo kit cho các subdomain trong V1.0.

---

## 1. Demo trong V1.0 dùng để làm gì

Demo dùng để:

- tạo trust
- chứng minh hệ có thứ thật
- nối public layer sang member depth

Demo không dùng để:

- giả lập backend chưa có
- tô vẽ quá mức
- thay thế value thật

## 3. Rule cho proof preview

- mọi proof preview phải đúng bản chất trust layer
- không được nói như thể proof là bất biến tuyệt đối
- mọi wording phải bám VC/trust docs hiện hành
