# 38_DEV_SEQUENCE_LOCK

## Mục đích của file

File này khóa thứ tự build của V1.0 để team không:

- làm economy trước trust
- làm wallet trước submission
- làm affiliate trước compliance
- làm work/market trước member + VC + EDU core

---

## 1. Nguyên tắc khóa

1. `Trust before economy`
2. `Access before expansion`
3. `Submission before proof claims`
4. `Proof before earning pathways`
5. `Clarity before speed`
6. `Completion before expansion`

---

## 2. P0 — khóa ngay trước khi build tiếp

P0 phải có đủ:

- runtime truth matrix
- language codex implementation
- public/internal separation
- domain boundaries
- entitlement spec

Nếu thiếu một mục P0, không mở wave mới.

---

## 3. P1 — core loop phải chạy

Chỉ được tập trung vào:

1. member auth / identity
2. EDU course player
3. submission
4. review
5. VC issue / proof eligibility
6. dashboard / next step cơ bản

Gate P1:

- user vào được flow học
- user nộp được
- submission được review
- completion đổi trạng thái đúng
- dashboard hiển thị được next step

---

## 4. P2 — harden core

Chỉ khi P1 chạy thật mới sang:

- AI tutor sâu hơn
- journey engine
- progress system
- mobile parity
- wave 1 hardening cho life / finance / invest / green

---

## 5. P3 — expansion có điều kiện

Chỉ khi P1 và P2 ổn mới được mở:

- work
- market
- ai tools
- community

Điều kiện:

- member core ổn
- VC gating rõ
- submission/review loop ổn
- dashboard state rõ

---

## 6. P4 — economy sâu

Chỉ khi các lớp trên đủ mạnh mới làm:

- affiliate runtime
- creator wallet
- partner access
- advanced automation

Không được mở P4 nếu proof/trust còn yếu.

---

## 7. Stop-the-line rules

Dừng ngay nếu team làm một trong các việc sau:

- build affiliate trước compliance gate
- build wallet trước work/market core
- claim earning pathway như live khi runtime chưa có
- để planned domain mang CTA như live destination
- mở public claim mạnh hơn runtime truth

---

## 8. Team sync

### Team 1

- owner P1 runtime contracts

### Team 2

- owner UI flow của P1 và P2

### Team 3

- gate owner xuyên suốt, đặc biệt ở stop-the-line

---

## 9. Definition of done

Sequence lock chỉ được xem là đạt khi:

1. team không mở wave sai thứ tự
2. mọi roadmap discussion quay về sequence này
3. economy lane không vượt trước trust lane
