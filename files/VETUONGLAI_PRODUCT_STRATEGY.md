### 4.2 LEARN vs EDU — Phân biệt rõ (Critical)

⚠️ **Đây là điểm anh chỉ định phải làm rõ — không được chồng vai trò.**

#### `edu.vetuonglai.com` = CONTENT LAYER ("Cái gì")

**Vai trò:** Thư viện nội dung học. Curriculum, lessons, programs, deep packs.

**Chứa:**
- Tất cả courses, programs, mini-courses
- Lectures, video, reading materials
- Bài tập, quiz, assignments
- Templates, worksheets, downloads
- Mini products $3–$9 (deep topics, packs)
- Cohort registration page

**User sees:** "What I can learn" — thư viện nội dung

**API:**
- `GET /edu/programs` — list all programs
- `GET /edu/program/{id}` — program detail
- `GET /edu/lesson/{id}` — lesson content
- `POST /edu/enroll` — enroll in program

#### `learn.vetuonglai.com` = PERSONAL LEARNING OS ("Cách nào")

**Vai trò:** Personal dashboard + pathway recommender + progress tracker.

**Chứa:**
- Personal dashboard cho user đã đăng ký
- AI-suggested pathway based on goals
- Progress tracker (% completion, streak, milestones)
- Skill gap analysis
- Recommended next program
- Cohort booking interface
- Verified credential display
- Learning streak gamification (light, không hype)

**User sees:** "Where I am, where to go next" — personal journey

**API:**
- `GET /learn/me` — user's personal dashboard
- `GET /learn/pathway` — recommended pathway
- `GET /learn/progress` — progress + completion data
- `POST /learn/checkpoint` — mark checkpoint complete
- `GET /learn/credentials` — display verified credentials

#### Quan hệ giữa learn ↔ edu

```
edu  = content library (read-only catalog)
learn = personal layer ON TOP of edu (uses edu data)

learn.vetuonglai.com renders:
  - edu data (programs, lessons)
  - + user-specific overlay (progress, recommendations, achievements)
```

**Không trùng vai trò:**
- Không host content tại learn (chỉ render từ edu)
- Không có dashboard tại edu (chỉ ở learn)
- edu là multi-tenant catalog; learn là personal view

### 4.3 WORK — Phân biệt với learn/edu

`work.vetuonglai.com` = **Work pipeline** — không phải learning.

**Chứa:**
- Brief listings (jobs available)
- Apply / submit work
- Portfolio builder
- Work history + ratings
- Payout dashboard
- Contributor program enrollment

**Quan hệ:**
- User hoàn thành program ở `edu` → có credential ở `vc` → mở quyền apply brief ở `work`

## 5. 9 NHÓM SẢN PHẨM × 3 PHASE

### 5.1 PHASE V1 — Foundation (Months 1–6)

#### Sản phẩm 1: Member Passport
**Subdomain:** `member.vetuonglai.com`

**Tiers:**
- Free Member ($0): Hồ sơ cơ bản, chọn mục tiêu, checklist
- Verified Member ($0 nhưng cần verify): Email + phone + 1 social link verified
- Pro Member ($9/tháng hoặc trong Annual $99): Portfolio + progress tracker + proof credits
- Business Member ($29/tháng): Cá nhân có dịch vụ / doanh nghiệp nhỏ — invoice tools, business profile

**Form đăng ký 3-step:**
- Step 1: Identity (email, phone, social OAuth)
- Step 2: Goals & profile (loại tài khoản, mục tiêu, quan tâm)
- Step 3: Path suggestion (auto-generated lộ trình)

**OAuth providers:** Google, Apple, Facebook, LinkedIn, X/Twitter, TikTok + email/phone fallback

**Liên kết mạng xã hội verified (sau đăng ký):**
- Facebook, LinkedIn, YouTube, TikTok, Instagram, X/Twitter, GitHub, personal website
- Mỗi link verified qua oEmbed/OAuth → đưa vào VC profile

#### Sản phẩm 2: Edu / Learning Foundation
**Subdomain:** `edu.vetuonglai.com` (content) + `learn.vetuonglai.com` (personal layer)

**Tiers:**
- Free Lesson ($0): 1–3 bài mẫu mỗi chương trình
- Mini Topic ($3–$9 lẻ): 1 chuyên đề + bài tập, mua riêng từng pack
- Program ($29–$99 lẻ): Lộ trình hoàn chỉnh + review + credential
- Cohort ($99–$299): 4-week cohort có mentor, có chấm bài
- Annual Membership ($99/năm): Toàn quyền truy cập

**V1 launch programs (đề xuất 3 chương trình mẫu):**
1. "Verifiable Portfolio Foundation" — học cách xây hồ sơ có proof
2. "AI Safe Use Practical" — dùng AI an toàn, không bịa
3. "Future Work Readiness" — kỹ năng làm việc remote

#### Sản phẩm 3: VC / Proof Infrastructure
**Subdomain:** `vc.vetuonglai.com`

**Tiers:**
- Free Proof ($0): Hồ sơ cơ bản, basic badges
- Pro Credential ($9–$19 hoặc trong Annual): Proof pack + verified portfolio + custom credential

**Nguyên tắc:**
- W3C VC Data Model v2.0 compliant

### 9.3 Discount logic

```javascript
function calculateAnnualPrice(years, tierBaseAnnualPrice) {
  // Months equivalent per commitment year
  const monthsPerYear = {
    1: 12,
    2: 11,
    3: 10,  // Anh đã chốt
    5: 9,
    9: null  // loyalty cap = $99/năm cố định
  };
  
  if (years >= 9) {
    return 99; // loyalty cap
  }
  
  const months = monthsPerYear[years] || 12;
  const pricePerYear = (tierBaseAnnualPrice * months) / 12;
  return pricePerYear * years;
}

// Examples:
// 1 year × $99 = $99
// 2 year × $99 × (11/12) × 2 = $181.50
// 3 year × $99 × (10/12) × 3 = $247.50
// 5 year × $99 × (9/12) × 5 = $371.25
// 9+ year = $99/year forever
```
