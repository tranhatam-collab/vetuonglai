# VETUONGLAI PERSONAL JOURNEY DASHBOARD SPEC

Version: 1.0
Last updated: 2026-04-07

## Dashboard của user gồm gì

- trạng thái hiện tại
- level phát triển cá nhân
- khóa học đang học
- thực hành đang theo
- tiến trình
- chứng chỉ / proof
- bước tiếp theo
- nhắc nhở thực hành

## Mức độ phát triển cá nhân

Không dùng để phán xét. Chỉ dùng để phản ánh user đang ở đâu và nên đi tiếp thế nào.

## Gợi ý bước tiếp theo

Dashboard phải giúp user không bị rơi vào trạng thái không biết làm gì tiếp theo.

## Trust / contribution score nếu có

Nếu xây score, phải giải thích rõ ý nghĩa và không tạo ảo tưởng gamification rỗng.
