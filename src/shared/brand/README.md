# Vetuonglai Brand Assets

Official web/payment logo set.

Files:

- `vetuonglai-icon.svg` — square app/icon mark, best for avatar/favicon/payment merchant icon.
- `vetuonglai-logo.svg` — horizontal logo/wordmark.
- `vetuonglai-payment-logo.svg` — 1200x630 card for payment-channel verification, social preview, and merchant profile upload.
- `vetuonglai-icon-512.png` — PNG export for payment providers that require raster image.
- `vetuonglai-icon-1024.png` — high-resolution square PNG export.
- `vetuonglai-logo-1600-square-preview.png` — square PNG preview generated from the wordmark SVG; use SVG for exact horizontal logo.

Usage rules:

- Use the SVG originals whenever accepted by the platform.
- If a payment provider requires PNG/JPG, use `vetuonglai-icon-512.png` first for merchant avatar/logo upload. Use SVG originals if horizontal logo or 1200x630 card is accepted.
- Do not add sales claims, income claims, or payment-status claims into the logo image.
- Keep the wordmark as `Vetuonglai`.
