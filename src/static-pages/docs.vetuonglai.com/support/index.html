FAQ

Tạo proof như thế nào?

Dùng dashboard trust.iai.one khi mở, hoặc API POST /api/proof/create trong Phase 1.

Hỗ trợ loại tệp nào?

Bất kỳ tệp nào có thể hash. Hệ thống dùng SHA-256 trên nội dung tệp.

Xác minh credential ra sao?

Mở verify URL hoặc gọi GET /api/verify/{id}.

Có dùng API miễn phí không?

Có. Free tier dự kiến có 100 API calls mỗi ngày cho verify và proof cơ bản.

Dữ liệu có bị lưu không?

Mặc định proof chỉ cần lưu hash, metadata cần thiết và timestamp. Tệp gốc không cần lưu vĩnh viễn.
