Hệ thống xác minh trust.iai.one

trust.iai.one hợp nhất proof.tranhatam.com, vc.vetuonglai.com và nft.iai.one thành một hạ tầng xác minh duy nhất. Định vị là verification infrastructure, không phải nền tảng NFT, blockchain hay Web3.

Proof Engine

Tạo hash SHA-256, timestamp và verify URL để chứng minh dữ liệu đã tồn tại tại một thời điểm.

Credential Engine

Phát hành, hết hạn, thu hồi và xác minh credential gắn với cá nhân, tổ chức hoặc thành quả học tập.

Asset Engine

Ghi nhận quyền sở hữu và lịch sử chuyển giao tài sản số khi credential hoặc metadata cần lớp ownership.

Luồng lõi

Upload -> Proof -> Credential -> Asset optional -> Verify Link

Verify link là điểm chạm công khai. Người xem không cần tài khoản, chỉ cần mở link để biết trạng thái valid, revoked, expired hoặc invalid.

Dashboard

Dashboard là trung tâm sản phẩm, gồm Overview, Proof, Credentials, Assets, Verify, API và Billing. Không tách thành ba sản phẩm rời rạc.

Gói sử dụng

Free dùng để thử proof. Pro mở credential. Business mở asset và API nghiêm túc. Enterprise mở tuỳ chỉnh, SLA và white-label.
