Bắt đầu với hệ sinh thái Về Tương Lai

Trang này dùng registry thật của hệ thống, không liệt kê domain giả hoặc dịch vụ chưa có trong cấu trúc hiện tại. docs.vetuonglai.com là lớp tài liệu công khai nối hệ web Về Tương Lai với trust.iai.one.

Bắt đầu nhanh

  1. Mở hub vetuonglai.com để hiểu bản đồ hệ sinh thái.
  2. Chọn lớp phù hợp: học, xác minh, tài chính, làm việc, thị trường, cộng đồng, AI, business, kids hoặc read.
  3. Dùng docs để xem trạng thái thật, API, pricing và legal trước khi tích hợp hoặc thanh toán.

Kiến trúc tổng thể

Hệ web Về Tương Lai là lớp nội dung, học tập, cộng đồng, thành viên và vận hành. trust.iai.one là sản phẩm xác minh riêng, nhận đầu ra từ hệ web khi cần proof, credential, asset hoặc verify link.

Vetuonglai ecosystem -> learning/content/community/business outputs
                       -> trust.iai.one
                       -> Proof -> Credential -> Asset optional -> Verify URL -> API/Billing
